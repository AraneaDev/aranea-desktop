# Omarchy 4.5.0 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Aranea's forks compatible with Omarchy 4.5.0 while retaining Aranea's existing desktop behavior.

**Architecture:** Port behavioral fixes into the existing Aranea components instead of replacing forks. Consume host-owned shell modules and collectors from Omarchy. Land independent port PRs before advancing the reviewed host pin.

**Tech Stack:** QML, Qt 6.12, reviewed Quickshell, JavaScript, Bash, Node test runner, sandboxed QML and headless compositor tests.

**Spec:** [Port triage and compatibility requirements](../specs/2026-11-10-omarchy-4.5-port-triage.md).

## Global Constraints

- Keep Qt 6.12 and the reviewed Quickshell build used by CI.
- Keep Aranea's notification inbox, quiet hours, shared popup system, unified clock, tray management, provider restrictions, and agent activity ownership.
- Port behavior into Aranea's existing components; do not overwrite forks.
- Change `.omarchy-version` only after all required ports and acceptance pass.
- No live desktop installation, lock, monitor, notification, or network changes are part of preparing this plan. Runtime acceptance uses the test sandbox.

## Evidence and workflow

Upstream comparison is exactly `v4.5.0-rc1` → `v4.5.0`, with commit identities
recorded in the spec. Use a local upstream checkout, referred to as
`$ARANEA_UPSTREAM_CHECKOUT` below. It must contain both tags. Do not compare with
the older maintenance release `v4.0.6`. PR #230 fixes that drift-tool error.

Read each upstream diff alongside the named Aranea files. Tests under
`tests/qml/` run through `tests/qml-behaviour.test.sh`; they use
`tests/qml/lib/QmlTest.qml` assertions, not QtTest test cases. JS tests load
QML-compatible JS through `tests/js/lib/load-pragma.js`. Every code task follows
red → minimal port → focused green → review → commit. Existing tests count when
they already reproduce the missing behavior. No new tests are needed for this
plan's prose.

Required CI prerequisite: fix `tests/agents-identity.test.sh` copying Ubuntu's
multicall `sleep` under provider names. Its observed failure is
`coreutils: unknown program 'claude'`; it is independent of dependency updates.
Keep that test-only fix separate from the ports.
